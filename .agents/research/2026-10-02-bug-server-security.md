## 验证

修复前对当前本机旧进程真实HTTP复现四项：坏cookie500、null JSON500、外域logout200、坏URL500。没有向真实账号写入。

修复后 Vitest 启动临时目录真实 server 子进程，验证无效输入、跨源/Host拒绝、分块超体积413、缓存304与文件更新200、符号链接404、管理员初始化→发码→注册→改密→旧会话401→重设撤销→旧码失效，以及跨昂贵接口账号限流。另有模块级时钟推进/Map容量/并发释放/上传超时与中断/激活码过期测试。

测试客户端最初用 Node fetch 自定义 Host 得401，后确认 fetch忽略该头；改原生http发送后421验证通过。这是测试工具假设失败1次，非生产修复回退。没有进行攻击真实公网、高负载压测或声称浏览器操作已通过。

## 再审查与限制

- 后台job在HTTP结束后仍执行，因此HTTP锁不能代替实际后台任务锁；两个池独立计数，不能宣称全局仅8。
- 恶意客户端断开时同步任务锁只在真实Promise结束释放，不能靠重连逃避占用。
- 密码/激活码不返回在列表或工作区接口；只能在管理员发码成功响应出现。
- 公网DDoS需上游边缘和源站防火墙；未掌握实际域名/CDN权限，本轮仅实现应用内保护并提供 deploy/native/SECURITY.md。Node本机单进程限制不跨进程共享，不代替边缘WAF。
