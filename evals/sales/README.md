# 中文销售场景评测

`npm run eval:sales` 使用固定 Promptfoo 0.124.1 运行 10 个合成场景，不调用模型。首次会由 npx 下载评测工具；它不是线上依赖。

`HARTA_SALES_EVAL_LIVE=1 npm run eval:sales` 调用 Harta 当前启用的模型，包括生成、事实复核和最多一次修正。使用的都是合成资料；缺少模型配置会明确失败，不会以模板充当模型通过。该模式会消耗已配置模型服务的额度。

案例包括首次开场、澄清、比较、异议、报价、售前售后疑问、拒绝、退款、老客新需求和资料注入。资料夹具同时放入其他业务、另一规格、待确认和过期资料，断言它们不会进入检索结果。更完整的版本竞争、到期、复制控制和权限测试在 Vitest 集成用例里。

规则通过只说明路由和资料过滤满足这些夹具。真实模型通过还经过同一报价检查与模型复核，但模型复核本身可能误判，不能替代人工判断或证明真实转化效果。检查最终回复是否先回答当前问题、是否自然、是否有下一步，不能只看总分。所有结果应注明模式和批次。

默认关闭 Promptfoo 遥测；不执行 share 命令。自定义 provider 未上报模型 token／费用，报告中的 0 不应解释为免费。
