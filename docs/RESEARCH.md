# Harta 需求研究与零投流内容

当前主流程：业务资料 → 需求与平台研究 → 一个主平台的六篇内容 → 用户按体验调整方向。

产品职责：直接交付获客打法、内容和咨询承接，不进行机构资质或准入审核，不以补交资质作为生成前置条件。内容中的具体事实不得编造；仍检查标题长度、平台字段、虚假承诺和不必要的敏感信息收集。

## 数据源

在「设置 → 需求研究数据源」中配置。仅管理员可保存和测试，普通用户不接触密钥。

- **SearXNG（开源，自建）**：配置实例根地址，Harta 调用 `/search?q=…&format=json`。必须启用 JSON 格式；公开实例往往禁用，不宜依赖陌生公共实例。配置后优先于 Brave。没有关键词搜索量或转化数据。
- **Brave Search（可选商业接口）**：没有 SearXNG 时使用。查询官方说明、行业需求和公开内容，保留来源链接与摘要。
- **5118（可选商业数据）**：在 API 商城开通「海量长尾词挖掘 API v2」，取得 API Key。网页会员不自动视为 API 权益。当前接入的是此接口，不宣称覆盖全部小红书/抖音专用接口。

环境变量也可配置，优先于设置文件：`HARTA_RSSHUB_URL`、`HARTA_SEARXNG_URL`、`HARTA_BRAVE_API_KEY`、`HARTA_5118_API_KEY`。设置文件为被 Git 忽略的 `data/research.json`，权限为 0600。环境变量覆盖时需修改进程环境才能替换。空密钥输入保留已有值；SearXNG 地址清空则取消该配置。

「测试连接」使用已保存的配置，各执行一次小查询，会消耗相应 API 额度；它能检查鉴权、返回格式和网络，不证明研究结论准确。

## 研究与证据

每次研究提取最多三个业务种子词、四个公开搜索查询。5118 每个种子词只查第一页30条，不自动翻页花费大量额度。搜索取每条查询前四个结果，再尝试读取前两份公开网页正文。

模型综合八方面：业务与成交条件、客户需求与购买阶段、平台流量入口、用户表达与视觉偏好、同行内容缺口、可信证据、咨询承接、执行能力与时机。新账号默认不依赖粉丝、出镜团队或现成案例。

每批保存独立研究快照：方向、查询时间、需求词、来源、证据范围、未核实项、方案。搜索摘要与已读取正文分别标记。第三方指数不等于线索，竞价竞争度不等于自然内容竞争度；没有来源不能称为已核实的平台规则。热度仅辅助，优先业务匹配、具体需求、咨询意图与可提供的证据。

成功且没有缺失警告的研究在同一客户资料、方向、数据源条件下复用24小时。资料或方向改变会重新研究。数据源失败不会伪造结果或阻塞内容生成，而是记录失败并使用业务资料及行业知识；模型方案生成失败也明确标注。

## 内容与调整

默认生成六篇完整内容，主平台一个，附发布顺序、用途、画面和选题理由。小红书保留封面、标题、正文；视频平台的可复制文案包含完整口播脚本。进入现有内容库，可编辑、复制、排期、导出。仍通过既有质量和合规检查。

2026-09-21 平台交付更新：小红书增加独立封面排版，标题在生成与编辑保存时按保守计数最多20字；抖音与视频号分别输出发布文案、封面、排版、开场、完整口播、分镜字幕和收尾，不把整段脚本并入标题。主阅读区直接展示完整平台稿。约定、边界和同题三平台示例见 `docs/PLATFORM-CONTENT.md`。

客户页「调整方向」接受最多2000字，保存后下一批采用。生成期间保存的新方向不会被旧任务覆盖；旧批次显示当时方向。历史内容用于避免重复；旧逐篇反馈不参与新主流程的选题决策，也不再展示新内容的反馈打卡按钮。历史台账和旧批次反馈保留为可选记录。

旧50条库存生成函数保留兼容测试，现有客户生成入口已改用六篇自然内容流程。

## 开源补充方案

- SearXNG：原生搜索服务已接入，查询返回真实链接和摘要。
- Crawl4AI：已接入公开正文读取，失败回退基础读取器并区分证据标记。
- RSSHub：已接入 36 氪最新快讯关键词匹配；无相关资讯时明确标记，不充当全网历史搜索。

原生安装、启动、停止与验证见 `deploy/native/README.md`，不使用 Docker。
开源工具可以提供公开材料和研究入口，不意味着免费获得全平台搜索指数、完整评论或真实获客数据。
