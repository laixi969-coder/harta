# Harta 导航与移动交互验收 · 2026-10-18

## 本次变更

- 产品界面统一使用 Harta；集成入口为「获客工作区」。导航、页标题、按钮、无障碍名称及前端导出文件名去掉第三方产品名称。内部路由、存储标识和来源许可声明保留兼容。
- 两套页面共用 `css/ui-foundation.css` 的品牌色、44px 控件尺寸、圆角、焦点、遮罩和空状态样式。手机输入使用 16px 字号，避免输入时意外放大。
- 860px 以下使用「菜单 + 当前页面」和完整文字导航抽屉；选页后收起，支持关闭、Esc、焦点返回。原生页面复用实际侧栏节点，保留权限和辅助入口；桌面侧栏继续可用。
- 手机内嵌工作区占用剩余视口，由工作区独立滚动，修复外层顶栏遮住内层菜单、双重页面滚动的问题。业务选择与全屏入口仍可用。
- 作品、评论、线索、任务、跟进和草稿共用简短空状态，筛选无结果提供恢复操作。私信空列表合并为一个空状态，保留连接会话入口。
- 公用弹窗改为原生 `dialog`，保持背景不可操作、可见关闭按钮、独立滚动和焦点恢复。Esc 在键盘阶段阻止默认关闭并调用原有关闭回调，避免未保存提醒挂在已关闭的父弹窗中；原生取消事件也保留保护。
- 图片预览逐层返回；修复嵌套取消事件关闭外层的问题。缩略图统一为52×62px，修复来源弹窗和草稿预览中未受尺寸约束的图片。原生作品详情刷新后能返回新渲染的作品入口。
- 原生后台轮询仅重绘内容变化的面板，避免未变化的表单失去焦点或输入节点。前台动作仍立即重绘。清除作品筛选同时清理输入草稿，恢复后焦点回到搜索框。
- 创作入口改为「新建内容」，来源操作统一为「参考创作」，已有草稿显示「编辑草稿」，实际发布仍在编辑器中单独操作。
