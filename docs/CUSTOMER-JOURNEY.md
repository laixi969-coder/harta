# 客户业务流程

客户分为新客户、在跟客户、已合作客户。入口在客户页分开呈现，并显示各阶段数量。

- 新客户：名称、行业、业务简介即可开始初步诊断。附件与沟通资料可选；保存轻量客户记录并生成报告。点击“开始跟进”进入下一阶段。
- 在跟客户：默认查看诊断报告，可分享报告、补充资料、更新诊断、记录沟通。点击“确认合作，进入建档”转为合作客户。
- 已合作客户：第一次进入业务资料，确认业务与获客方向后主动生成首批内容；已有内容的客户直接进入内容交付。允许直接录入已合作客户。

阶段切换沿用客户 ID、资料、报告与跟进记录，不重新建一份客户。历史存量记录归入已合作客户；未标记阶段且已有报告的记录归入在跟客户。新创建的诊断记录保留新客户阶段，直到用户开始跟进。

内部保留 track 拓新/存量，兼容已有生成和交付逻辑；stage 表示 new/following/cooperating。阶段调整不自动生成内容，后台任务运行期间不可切换。

## 业务不变量

1. 客户是一条持续记录，阶段是这条记录的状态。新客户的初步诊断不等于已开始跟进，跟进记录里的成交也不自动代表已确认服务合作。
2. 每个操作只有一个业务目的：建档只保存客户；诊断接口只出报告；内容接口只为合作客户生成内容。直接录入合作客户也不自动开内容任务。
3. 报告是沟通交付，平台内容是运营交付。诊断样例不因缺完整封面而阻断报告下载；实际文案的真实性检查继续保留。
4. 切换客户时不能串用上一位客户的报告 ID、业务草稿或延迟响应。合作客户默认选择内容，只有显式选择时才打开其历史报告。
5. 追加资料意味着所有历史批次继续被引用。每份附件和摘要的标识必须包含所属批次；清理任务不能只保留最后一批。
6. 异步结果只能更新其仍然有效的任务或字段。超时任务不再具有写回权；报告修复不能覆盖期间的人工编辑和业务资料，也不能恢复已删除报告。
7. 保存工作区采用临时文件替换，保存成功后才释放不再引用的附件。无法读取工作区时暂停孤立资料清理。

## 对抗式审查（2026-09-21）

已复现并修复：旧阶段接口绕过任务锁、重复设置类型导致阶段回退、合作建档自动启动内容、误用诊断接口启动内容、同毫秒客户 ID 冲突、超时任务无法重试及晚返回覆盖、旧附件被清理、附件编号撞号、异步修复覆盖新资料、无效报告 ID 回退到旧报告、快速切换客户的响应串位、切换客户丢失未保存业务草稿。

验证包含隔离工作区的异常时序测试、磁盘保存失败注入、损坏工作区下的资料清理测试，以及正常生成、平台检查、报告导出和资料解析回归。未执行真实客户的阶段变更、附件删除或模型付费生成。

最终验证：34 个测试文件、287 项测试通过。浏览器实测在两位客户间切换，未保存业务草稿按客户隔离并可恢复；测试文字已清空，未提交到客户资料。

补充上传采用追加模式，保留旧附件及其批次，新诊断与内容读取所有批次。旧替换接口仍支持显式替换；明确清空资料时释放不再被其他客户引用的批次。业务简介、城市、沟通与合作范围可在客户工作区持续补充。
