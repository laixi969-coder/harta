# 平台内容交付

每篇交付必须能对应平台的发布与制作动作。一个主平台六篇仍是默认批次；跨平台要重新编排内容，不能把同一正文改个标题就算适配。

| 平台 | 每篇必交付 | 编辑重点 |
| --- | --- | --- |
| 小红书 | 笔记标题、封面文案、封面排版说明、笔记正文 | 标题补齐需求与场景；封面突出一个问题；正文回答问题 |
| 抖音 | 发布文案、视频封面文案、封面排版、开场、完整口播、分镜字幕、收尾 | 尽早让画面展示具体问题，再用例子解释，给出一个下一步 |
| 视频号 | 发布描述、视频封面文案、封面排版、开场、完整口播、分镜字幕、收尾 | 说明对象，保留完整上下文与适用边界，转发后仍能独立理解 |

上述是本产品的创作与验收约定，不是平台算法规律。时长、图像比例与封面字数是编辑建议。官方创作后台本次未提供可公开读取的完整规则，不据此添加未经证实的硬限制。

## 小红书标题和封面

标题按用户要求不超过20字。本工作台使用保守计数：汉字、英文字母、数字、空格、标点都计1，Unicode码点计数；这不是对平台所有组合emoji及英文计数行为的精确复刻。生成时不合格退回模型重写，失败不作为新批次交付；编辑保存超过20字则拒绝。禁止自动截断破坏意思。

封面建议6—12字、最多两行，只突出一件事；标题和封面不要完全重复。封面排版必须写明断行、主次文字、画面主体、留白与裁切检查。不要把“效果好”“注意了”当作信息，医疗题材不使用恐惧画面与疗效承诺。

例：封面“半天假／够看完吗”；标题“HPV就诊前，半天假够吗”（12字，包含HPV三个字母和标点）。正文分别说明需要向官方窗口确认的预约节点，不承诺半天完成。封面主问句大字，辅助画面用不标具体时间的预约时间轴，不用真实患者挂号单。

## 同题如何改成视频

以下是HPV就医流程的表达样例。Harta负责内容与获客打法，不开展机构资质审核，也不把补交资质作为出内容的前置条件。具体业务事实按客户提供的信息使用，不编造价格、地址或疗效。

### 抖音样例：先看到问题

发布文案：只有半天假？就诊前先确认预约节点。

封面：半天假／够看完吗。竖版画面，问句在中上部，下面是一张原创空白时间表，留开底部与右侧控件位置；实际发布时核对裁切。

开场：镜头推向只留出半天的日历；第一句“挂到号，不一定代表半天能把事情办完。”

完整口播：挂到号，不一定代表半天能把事情办完。如果你正在安排HPV相关就诊，先向目标医院的官方窗口确认：去哪个院区、几点报到；如果医生评估后需要检查，是否另约；结果从哪里查询。你可以直接问：“我想安排就诊时间，请问这些节点怎么确认？”拿到明确回复，再安排请假和交通。具体检查准备按接诊机构要求执行，不要照搬别人的时间表。

分镜建议：

| 时间 | 画面 | 对应口播与字幕 |
| --- | --- | --- |
| 0—3秒 | 日历只圈半天 | 挂到号，不一定半天办完 |
| 3—15秒 | 院区、报到、检查预约三张原创卡依次出现 | 向官方窗口确认三个节点 |
| 15—30秒 | 展示完整问句 | 我想安排就诊时间，请问这些节点怎么确认 |
| 30—40秒 | 回到日历，空白安排待确认 | 确认后再安排请假；具体要求看接诊机构 |

收尾：给出可直接问官方窗口的一句话，不用评论暗号领资料，不引流个人微信。

### 视频号样例：把事情讲完整

发布描述：给准备安排HPV相关就诊的人：先核对时间节点，再安排请假和交通。

封面：就诊请假前／先问清时间。左侧两行清晰大字，右侧为原创简化时间轴，不用惊吓表情或“半天搞定”的承诺。

开场：平稳口播或文字卡；第一句“这段内容说给正在安排就诊时间、又不方便反复请假的人。”

完整口播：这段内容说给正在安排就诊时间、又不方便反复请假的人。如果你准备进行HPV相关就诊，需要把预约成功、到院报到、医生评估后的检查安排，以及查询结果分开确认。不同医院的安排可能不同，不能用别人的一次经历推断自己当天一定完成。联系目标医院的官方窗口时，可以问：“我想了解院区和报到要求，如果后续需要检查，怎样确认预约和结果查询方式？”等机构把这些节点说明白，再安排假期与交通。这段内容只帮助准备流程问题，具体诊疗和检查准备以接诊医疗机构说明为准。

分镜建议：0—8秒说明受众；8—25秒展示四个就诊节点；25—45秒展示可直接使用的问句；45—60秒总结“先确认安排，再决定行程”及适用边界。时间仅作拍摄节奏建议，录制后按自然语速调整。

## 实现与兼容

- `js/platform-content.js` 为前后端共享字段与标题计数规则。
- 新批次标记 `origin.deliveryVersion: 2`，缺必需字段或标题超限不能交付。
- 主阅读区展示完整平台稿，不再把标题、封面藏在正文卡下面。
- 缺字段旧档如实显示缺失，允许编辑补齐；不假装已经有分镜。
- 编辑覆盖、检查、复制、导出与整篇归因都保留新增字段。
- 旧批次仍保留；当前两家正式客户最新小红书批次已补封面排版。
