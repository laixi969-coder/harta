# Harta 改版功能保留与页面对照

2026-10-31：用户要求原 Harta 与 Flowso 功能都要保留且在最终产品中呈现。改的是排版、布局与 UI/UX；相似功能整合后仍须覆盖原操作。Flowso 历史数据不迁移，Harta 现有记录继续保留。

本表是新版页面的设计与验收合同，不是完成证明。新版未来工作室的导航、经营总览、创作入口和共享主题已实现；其他功能是否完成仍须逐项验收，当前实现边界见 [移植对照](FLOWSO-HARTA-MAPPING.md)。表内“验收”是必须完成的动作，未给出测试证据的项目均待验。按现有导航与 Flowso 页面操作整理，仍须继续拆解组件和服务端动作，不能以页面覆盖冒充全部功能覆盖。

## 两条主线

首页与主导航并列呈现主动截流、内容创作。内容创作中再分“信息流创作”和“小红书 / 抖音图文与视频”两个入口。信息流包含付费投放与自然推荐；入口、平台、形式、传播用途各自独立。共同使用作品库和客户跟进，保留来源，不重复计算联系人。

## 已发现需要进一步逐项核对的差异

- Flowso `persona/page.tsx` 的资料评估、单字段采用和整批采用已补齐；Harta 另支持草稿独立持久化、撤回与版本冲突保护。评估展示覆盖和建议，不沿用字数推算的理解度分数。内容获客页有“创作者资料”直达入口；咨询与引流入口已整合进版本化资料，内容创作页有“咨询承接”直达入口；支持草稿、明确采用、撤回及生成依据快照，不能据此把产品页其余操作全部视为完成。
- Flowso `standards/page.tsx` 的新增规则与级别切换已接入；Harta 支持删除、版本历史、精确词句规则及人工核对规则。生成与改写检查阻止级别的自动规则；原生发布登记服务端要求人工确认与当前内容/标准一致。内嵌作品草稿的「复制发布文案」也已接入同一套规则；平台自动代发维持关闭，草稿保存与素材下载不冒充发布。
- Flowso `settings/page.tsx` 与 `api/wechat/route.ts` 有公众号绑定、断开及文章同步；Harta 已接入等价入口与实现，隔离模拟接口验收通过，真实公众号账号环境尚未验收。抖音官方接口、小红书连接及各平台帮助也需分别验收，不能统称“平台已接通”。
- Flowso 选题分组已整合到下文的选题库；创作任务标签、评论洞察历史等仍需按原动作核对，不能用现有增长目标选项替代所有任务语义。

这些属于保留范围内的待核对或待补齐项，不是被设计移除的功能。历史数据不迁移不等于取消用户今后导入新内容、评论或效果数据的能力。

## 独立作品草稿的发布文案核对

「内容创作 → 作品草稿 → 新建 / 编辑 → 发布前核对」现使用本业务的创作标准检查标题、正文与话题。自动词句规则、人工确认与级别语义沿用原生创作标准；复制前重新读取服务端规则，正文、话题、平台或形式改变都会使旧确认失效。业务、用户隔离及旧规则拒绝在服务端验证，浏览器还会拒绝复制请求期间已被编辑的旧文案。

本业务保存最近 100 次准备复制的记录，界面可查看最近 20 次及当时文案、规则版本和人工确认项。`copy_prepared` 只表示服务端已为这份文字完成核对，不表示剪贴板成功，更不表示平台发布。剪贴板失败时保留记录并显示明确重试提示。图片、视频画面与事实仍需人工核对；不以文本匹配宣称媒体内容已检查。

`test:studio-standards-ui` 验证规则阻止与提醒、人工确认、实际剪贴板内容、规则更新和本地编辑竞态、核对历史与手机布局。全量单测 105 文件 / 1007 项通过，TypeScript 与内嵌工作区构建通过。公众号绑定、断开、文章同步和其余原动作差异继续保留在未完成清单。

## 2026-10-31 咨询与引流入口

对照 Flowso `persona/page.tsx` 的 `settings.divertTo`，Harta 在“内容创作 → 咨询承接”提供直达入口，并整合进创作者资料的版本管理。支持独立保存草稿、采用此项、整批采用、撤回和历史回查；旧客户端省略新增字段时不会清空已采用入口。不同平台的承接方式可分别填写，保存不证明链接有效或平台能力已开通。

## 选题库与制作内页整合

内容创作 → 选题与雷达 → 选题库：手写选题、需求候选和雷达安排共用本周 / 下一批 / 待定，另有制作中与已舍弃视图；本周最多 5 条，旧雷达入口也执行同一上限。支持编辑、移动、舍弃、恢复和移除已舍弃安排；不删除来源作品或已建制作稿。可逐篇或为本周全部选题生成制作稿，固定每篇选题、参考来源和目标。模型失败保留制作稿，重试只补空白；来源变更须核对刷新，旧版本更新和生成期间变更均拒绝覆盖。可明确另建制作稿并回查旧稿，不偷偷替换用户已编辑内容。

对应 Flowso `library/page.tsx` 与 reducer 的手写灵感、分组、每周上限和 create-script 操作。Harta 的本周批量生成实际处理所有已安排选题，而非只处理首条。现有需求选题「采用到创作方向」继续保留；不填虚构发布时间和互动数。`lib/topic-board.test.mjs` 与 `test:topic-board-ui` 覆盖来源变化、并发编辑、批量图文 / 视频生成、失败重试、按业务隔离、刷新、分页及手机布局；外部模型由隔离测试接口替代。

内容库 → 查看与制作：直接展开三标签制作工作台，桌面编辑与当前草稿预览并排、手机单列，作品横向选择。原脚本、直播、封面、素材、检查、采用和交付动作保留。入口、保存、预览、未保存输入与原稿隔离由 `test:future-studio-ui` 验证，完整制作与素材竞态回归通过。所有业务内页的视觉重构尚未完成。

制作工作台可为单篇作品或直播草稿单独选择打法、关闭打法或沿用业务设置；直播和图文 / 视频的选择独立保存。切换只影响之后生成的建议，不会改写现有草稿；选择不再适用于当前条件或已删除时须重新选择。生成期间其他窗口修改了任务或打法会拒绝返回旧建议。周排期逐条显示任务，并对已标注的任务分布提供规划提示，未标注数量单列。
