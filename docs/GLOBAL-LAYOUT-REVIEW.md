# 全站信息布局整理 · 2026-09-21

用户要求将分组、列宽与留白问题作为全站问题处理。本轮保留已确定的功能色块，调整结构和内容组织。

| 区域 | 本轮处理 |
| --- | --- |
| 工作台 | 统一章节间距、历史批次网格、依据说明面板、空状态区域 |
| 内容库 | 沿用双栏阅读与平台字段分区，统一章节边界；未改变文案、编辑或复制逻辑 |
| 需求研究 | 分离导入与词库、方向与研究结果；空库时导入和方向并排；研究结论按标签分组 |
| 业务资料 | 摘要、主题组、来源与转录分区；有资料时隐藏冗余空状态说明 |
| 新建客户 | 合作信息在左，文件与销售补充在右；窄屏按顺序展开 |
| 客户及报告列表 | 统一间距、动作换行和最小列宽 |
| 跟进记录 | 保留已实现的录入与记录双列，纳入本轮主题与响应式回归 |
| 团队 | 行业概览与最近原话并排，原话用分隔行 |
| 设置 | 数据源字段分组双列，模型区章节分隔，修复浅色表单控件对比度 |
| 登录注册 | 品牌与表单平衡，表单垂直居中，页签间隔统一 |
| 独立报告 | 居中1120px版面、章节分隔、需求/机会/平台各自分组；打印保留独立规则 |

## 验证范围

- 257 项 Vitest 测试通过。
- 使用隔离的模拟 API 检查已登录业务界面：四个工作区、客户、新建客户、报告列表、跟进、团队、管理员设置；深浅主题，1512px和390px均无文档横向溢出、无页面脚本异常。
- 包含内容及检查说明的样例验证了字段保留、分组数量和桌面/手机布局。
- 登录、注册及三个静态报告以实际路由检查1512px和390px，无横向溢出或脚本异常。
- 模拟数据只存在浏览器测试中，没有写入业务服务器；此次未测试真实密钥、文件上传或生成调用，未对这些逻辑作更改。
