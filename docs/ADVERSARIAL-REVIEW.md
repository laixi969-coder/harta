# 内容依据与导入链路审查

本次按四个条件检查：输入能否安全处理、指标能否支持结论、业务归属是否成立、资料能否进入生成且保持账号隔离。

## 已修复

- 同词、同来源、同日的冲突观测原先按最后一条覆盖，可能把热度算到10分以上。现在保留冲突集合，冲突数据不参与热度或趋势加分，热度上限10分。
- 原先可能挑选历史最高热度，并在最新日期冲突时退回旧的上升趋势。现在只采用最新观测的热度，趋势的最近两个日期必须均无冲突。
- 宽泛行业归属原先可以覆盖具体品类不匹配。现在优先检查具体品类，并对品牌归属、明显否定经营表述分别核对；调整方向不充当经营事实。
- 非法千位分隔符和伪日期不再被当作有效指标。客户名称变化使研究缓存失效，未来时间戳不能命中缓存。
- Office 文件在正文解析前执行压缩包条目数与实际解压总量限制；导出 CSV 防止空白前缀绕过公式转义。
- 公网读取检查补上十六进制 IPv4 映射的 IPv6 内网地址、扩展链路本地、多播和带账号密码的 URL。

## 验证

`npm test -- --reporter=dot`：32 个测试文件、255 项测试通过。新增用例覆盖冲突/旧指数、品类及品牌误匹配、非法数字及日期、Office 解压超限、CSV 公式转义、特殊地址写法。现有测试覆盖导入与导出的数据保留、账号隔离、外部来源适配和六篇自然内容生成。`git diff --check` 通过。

## 边界

业务匹配仍是保守的文字规则，不能证明经营资质；指数只能作为选题参考。搜索与模型输出受外部服务及模型质量影响，测试不证明真实获客效果。5118 未配置权限时不会产生其 API 数据。网络地址检查不等同于操作系统级网络隔离。当前审查覆盖新增功能及相关调用链，不是全仓库安全认证。
