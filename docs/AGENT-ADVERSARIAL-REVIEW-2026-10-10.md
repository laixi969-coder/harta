# 智能体逻辑与对抗式审查

范围：本轮未提交的内置助手、试运行、质量审读与 UI 改动；追踪到正式找客、接待起草和发送前复核入口。未修改网络代理。抖音真实连接和收发验收仍受此前网络问题阻塞，不在本报告中宣称通过。

审查原则：配置意图不等于执行权限；完成一次拒绝处理不等于验证生成能力；旧版本验收不等于新工作流验收；出现相同数字不等于来源支持；外部错误文本不具备内部可信身份；审读结果缺失不等于通过。

## 已修复

| 问题 | 影响 | 修复与反例 |
| --- | --- | --- |
| 正式入口只检查 enabled，未检查工作流版本 | 已启用旧助手仍可启动找客、接待和使用旧草稿 | 统一当前配置、知识哈希、工作流版本及有效草稿验收；三个入口都校验。测试篡改旧工作流记录后拒绝正式操作 |
| hold 场景完成即可以启用 | 只测试拒绝联系可绕过生成验收 | 停止营销样例保留为有效处理记录，但不能代替产生有效草稿的试运行 |
| 按错误文字前缀信任质量错误 | 提供商伪造前缀后，原始错误可能进入工作区 | 模型与审读错误在边界统一脱敏，仅本地类型化校验错误可展示 |
| 数字使用字符串 includes | 来源 14000K 可错误支持输出 4000K | 提取完整数值与单位，规范全角、空格、大小写后精确比较 |
| 审读未验证结果是数组 | `{length:0}` 被误认为无问题 | null、undefined、字符串及伪数组均失败，不生成可用结果 |
| 预设用途和职责可不一致 | 内容工作流带接待权限，用户看到的用途与行为不符 | 服务端校验预设单一职责，UI 禁止修改预设职责；通过更换用途切换 |
| 新建绕过配置验证 | 新建/复制与保存的约束不一致 | 创建同样经过配置校验；默认角色名限制长度 |

保留与复核：租户隔离、跨业务绑定、知识更新、保存新版本时的旧任务、暂停后的迟到模型回复、超时、自动修正次数、无模型模板标识，以及真实发送前的既有核对。模型输出和修正反馈始终作为数据，不开放外部操作工具。
