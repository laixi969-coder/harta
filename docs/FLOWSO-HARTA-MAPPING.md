# Flowso 功能在 Harta 的位置与验收边界

当前界面状态：顶部导航、经营总览、双创作入口、共享深浅主题及三标签制作工作台已实现。制作入口直接展开，编辑与真实草稿预览并排；其余业务详情仍待逐页优化。选题库已提供手写、分组、共用本周上限和逐篇 / 本周制作稿生成，详细边界见下方及 FUNCTION-PRESERVATION.md。本文后部较早的“新版待实现”是历史记录，不代表当前状态。

新版布局的功能保留与页面合同见 [FUNCTION-PRESERVATION.md](FUNCTION-PRESERVATION.md)。该表同时覆盖 Harta 原能力和 Flowso 能力，并单列尚未证明等价覆盖的操作；本文件主要记录当前实现边界。

2026-10-31 功能保留约束：用户明确要求原 Harta 与 Flowso 的功能都要保留并在最终界面呈现；本次改变排版、布局与 UI/UX，不通过删减功能换取简洁。相似能力可合并入口和底层数据，但须逐项证明原有操作、结果、历史与设置仍可到达。只存在于代码或接口、没有可发现入口，不算完成。Flowso 历史数据仍不迁移。 此表还需与原 Harta 全量功能入口清单交叉核验，不能仅凭本表认定两套产品全部功能已保留。

本表用于跟踪功能整合；Flowso 的历史账号和数据不迁移。相似功能优先复用 Harta 的业务、作品、线索和内容版本，不因为界面有入口就认定已达到功能等价。
