# 客户工作区改版

方向：克制、清晰的产品界面；保留青灰与青绿双主题。卡片用于完整内容、独立待办和资料摘要，目录、标题、筛选与辅助信息采用开放排版。

- 当前客户名称作为主标题，全部客户待办进入独立入口。
- 内容、需求研究、业务资料、全部待办各自展示，原有节点与业务事件保留。
- 今日内容采用左侧目录、右侧正文预览，可切换单篇或浏览全部。筛选时切回全部结果，避免单篇预览遮住匹配项。
- 历史、适用条件、发布检查、筛选排期与导出按需展开；风险计数及既有复制限制继续生效。
- 手机下目录横向浏览、正文单列；工作区导航保留文字和可见选中状态。

验证：33个测试文件、257项测试通过。Chrome实测HPV治疗客户显示6篇目录和“浏览全部”，切换后仅一篇正文可见；需求研究独立显示100词库；390px单列、整页scrollWidth379px，导航按钮约52px高；未见控制台error。未修改客户内容、指标或医疗判断规则。未进行物理手机测试。
