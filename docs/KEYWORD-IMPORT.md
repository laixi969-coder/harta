# 业务关键词库

在当前业务的「业务关键词库」选择 **领域 / 产品品类 / 品牌**，填写归属名称，上传文件，点击「导入并自动梳理」。词库归属于当前账号的当前业务，不会自动共享给其他客户或账号。

支持 XLSX（多工作表）、CSV、TSV、TXT、Markdown、DOCX、文字型 PDF。旧 XLS/DOC 请另存为 XLSX/DOCX；扫描 PDF 需要先转为文字。XLSX 使用 ExcelJS 直接读取，无需 LibreOffice 或 Docker，不执行公式，只读取已有的缓存结果。

- 表格自动识别前10行中的关键词表头；支持“关键词、搜索词、长尾词、关键词名称、keyword”等列名。无表头时第一列按关键词读取，其他列作为原始字段保留。
- 原有品类、品牌、平台、指数、日期、备注保留在来源记录中。重复词仅在品类、品牌、平台相同时合并，并保留每次原始观测，不把零当缺失，也不把不同指数相加。
- 去重后的全部词按规则拆解修饰词、意图及了解/比较/咨询阶段，这些分类属于推断。
- 配置模型后，每批按意图均衡选取最多120个词，梳理主题、场景、内容切口；界面显示实际覆盖数量。模型失败时保留词表与规则分类。
- 长文档分段提取原文中出现的关键词；模型虚构的词不被接收。提取并不保证穷尽文档全部关键词。短 TXT/Markdown 词表可逐行或以逗号、顿号、分号分隔，无需模型。
- 可检索、导出整批整理结果、移除批次。页面每批最多展示100个匹配词，其他词仍保存在库中，可搜索或导出查看。

每次需求研究按归属与意图均衡取最多80个词，随内容批次轮换。选中的原词、归属、原始字段、主题建议写入研究快照，用于查询规划、选题和内容生成。导入、移除或轮换改变研究指纹，旧快照不被覆盖。用户提供的指数明确属于导入数据，不冒充实时查询，不自动视为本品牌的真实资质或业绩。

限制：每次最多5个文件，单个10MB、合计20MB；每批最多3000条原始记录；每个业务最多10批、合计10000个整理后关键词。超限明确报错，不悄悄截掉词表。文档正文每份最多12万字。上传原文件在解析后清理，只保留词条、来源记录及分析结果；请自行保留原件。

下载接口：登录后 `GET /api/keywords/template`、`GET /api/keywords/export?customerId=…&batchId=…` 返回 CSV 附件，支持内置浏览器下载。

接口：登录后 `POST /api/keywords/import`（multipart，customerId、scopeType、scopeName、files）、`POST /api/keywords/remove`（JSON，customerId、batchId）。解析完成后重新读取工作区再保存，避免覆盖并发的业务方向或内容更新。账号同时只运行一次关键词导入。


## 产品 × 平台内容依据

已导入的旧词库也会自动按当前规则生成内容依据，无需重新上传。页面分别展示各平台的候选需求、原始指标、选题建议、优先级、咨询承接及证据缺口；最多展示12个平台，每个平台12项候选，总候选展示24项，完整词库仍可检索与导出。每次研究和生成保存当时的依据快照。

所有词均进入规则筛选。业务文字匹配40分、意图最多25分、具体性最多15分；仅在对应平台内使用同来源、同产品/品牌、同指标名称、同统计周期、同日期的关注度比较（最多10分），同口径近期两次观测上升再加5分。90天前、未来或日期未知的指标不加热度分；零值保留，零基数不计算增长百分比。所有分值都是Harta的内容规划建议，不是平台算法或获客概率。

竞价指标不推断自然流量竞争，笔记数/视频数只保留为内容数量参考。没有业务匹配或未确认品牌的词先列为待确认；不能因为指数很大就排为可直接制作。没有标明平台的词仍可用于一般需求研究，但不能冒充某个平台的热度。PC/移动标签本身不能确定是哪个搜索平台。

模型生成会结合产品资料、平台专属依据和外部研究决定表达、画面与咨询承接。词库提供依据，不要求逐篇反馈打卡，也不承诺导入词就能获得流量。5118未授权的接口仍不自动抓取付费数据。
