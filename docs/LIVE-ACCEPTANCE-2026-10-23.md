## 发现与修复

1. 抖音评论入口的旧等待逻辑在过滤隐藏元素前取第一个匹配，可能盯住其他布局残留的隐藏控件；真实页面还存在加载延迟。现在先选可见控件，优先评论标签，再使用图标；将有界加载等待从15秒调整为30秒，保留验证码检查和暂停行为。缺少入口且未取得评论响应时仍报错，不假装成功或返回空评论。真实任务恢复后已取得5条评论。
2. 研究规划没有给模型实际日期，本次真实请求生成了带2024年份的“当前规则”查询。现在查询规划与策略都携带本次研究日期，要求区分历史规则与当前规则，并更新缓存版本。两次真实模型请求验证后，查询采用2026年份；日期上下文不能保证所有外部信息永远准确。

外部研究本次得到4个来源，但部分搜索与RSS无结果，结果保留为partial及相应警告，未宣称全部平台规则已核实。真实采集没有验证客户私信发送、发布或成交转化。

## 可重复验证

`node scripts/check-platform-controls.mjs` 使用本地HTML验证隐藏图标、延迟出现的评论标签、图标回退、标签优先和缺失入口，不访问平台、不收费，已加入CI。

付费验收脚本不加入CI；仅使用本机已有登录会话，多个账号时必须指定账号，不输出密钥：

```sh
HARTA_LIVE_EMAIL='本机已登录账号' HARTA_LIVE_RESULT='/绝对路径/验收结果.json' node scripts/check-live-model.mjs --allow-paid
```

会真实调用当前模型，创建带验收标记的业务并保留结果。默认服务地址为 `http://127.0.0.1:5173`，可通过 `HARTA_LIVE_ORIGIN` 修改本机端口。没有 `--allow-paid` 时立即退出，不发起请求。
