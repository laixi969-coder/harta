# PRD v0.3 补全与 UI/UX 评估

日期：2026-10-08。依据：`prd.MD` v0.2 新增的智能体、执行逻辑与 P01–P13 页面规格。用户已确认按现有视觉增量实施。本轮未部署或操作任何真实平台账号。

## 判断

**UI/UX 需要调整，现有视觉体系可以继续使用。** 新 PRD 增加了长期保存的业务角色和可追踪任务；原来只有“导入／生成／登记”的界面无法完整表达角色版本、运行记录和权限边界。最有价值的改动是补齐这些工作对象，并保持业务范围与状态一致。

设计取向：product，SOUL 6、SPECTACLE 2、DENSITY 7。沿用用户已确认的近黑底、橙红与蓝紫色块、冰蓝／雾绿辅助色、中文正文及深色胶囊控件。无需增加 WebGL、背景动画、营销式超大标题或另一套装饰卡片。避免将“高级”误解为改变既有品牌。

## 发现与处理

| 优先级 | 修改前的证据 | 用户影响 | 本次处理 |
| --- | --- | --- | --- |
| P1 | `index.html` 无智能体页面；获客数据只含任务、证据、线索、账号与发布 | 第 15 节缺少可操作对象，无法保存／回查策略 | 新增智能体入口与 `business-agents.mjs`、`agent-ui.js`；保存版本、试运行与日志 |
| P1 | `summary()`、`resultsView()` 从整个工作区统计，下方列表才按业务过滤 | 切业务后数量与对象不一致 | 选择器移到获客汇总上方；汇总、复盘与列表统一按当前业务 |
| P1 | 点击来源任务仅展开所有历史任务 | 无法确认某条证据属于哪次执行 | 单次任务详情显示输入、版本、平台结果、证据与停止原因，可返回与导出 |
| P1 | 新咨询到达后旧草稿仍显示“复制草稿” | 容易继续使用过时回复 | 同账号、同渠道旧草稿标待更新；服务端拒绝继续复制；真实历史发送仍可登记 |
| P2 | 咨询登记可选同业务所有平台账号和内容 | 用户提交时才发现平台／账号冲突 | 联动过滤账号、内容和线索；唯一账号可默认选中 |
| P2 | 咨询登记完成后表单仍展开，挤压会话区域 | 下一步处理不突出 | 保存后收起登记区；现有会话与跟进保持可用 |
| P2 | 配置与试运行会在轮询中重绘 | 可能丢失输入或焦点 | 配置按角色／版本隔离保留未保存输入；试运行按角色保留样例，恢复输入焦点，提交期间避免重绘 |

本轮没有替换旧今天首页、客户页、原有内容卡、跟进记录、全组或设置页。新增待办仍位于双路径获客页；统一全局首页和完整三栏会话台为后续工作，不在本次假定已实现。

## 智能体实际能力

1. 读取当前业务生成草稿，预填已知服务区域、关键词与有效条件；未知人群不虚构。
2. 保存角色名称、职责、平台、人群、有效条件、关键词／排除词、交流、转人工与内容方向；版本保存采用基础版本检查。
3. 引用业务资料与已读取附件；版本保存知识摘要，试运行保留具体输入快照，资料变更时提示重新保存和测试。
4. 绑定当前业务的账号资料，可暂停绑定；只允许草稿动作，无法绕过服务端改成自动收发。
5. 试运行接受真实原文／来源或已有同业务证据。意向排序目前是可解释规则；模型可用时生成草稿并调用现有事实核对，模型未配置时明确显示规则与模板。
6. 运行保存版本、原文、知识、步骤、输出、耗时与结束原因。费用和模型 token 未接回，展示未统计。
7. 支持启用、暂停、归档、同业务复制。启用要求当前版本已试运行、有效条件已填写且知识未变化。不会因此自动开始所有任务。
8. 已启用的找客角色可用于公开摘要任务，采用关键词与排除词并保存固定版本；暂停角色停止关联任务的后续写入。

**边界：**创作与接待职责目前用于策略配置和试运行，未接入统一生产调度。普通账号真实登录、评论／私信同步、自动发送／发布、批量媒体分发、结果核实、金额预算与自动接待主角色冲突管理仍未实现。第一阶段的内部补充不能代表完整 PRD 或真实平台流程通过验收。

## finesse 检查解释

静态检测在原有样式中提示侧边强调线及历史 `--paper` 命名；未报告 P0。它们属于既有样式，不构成更换已确认视觉的理由。新模块只使用既有语义色与控件，不新增默认渐变字、假指标、装饰动画或伪平台成功状态。

本任务是产品工作台，检查采用 product-ui 标准：正文可读性、状态、表单和任务效率优先。品牌落地页的英雄动画、大标题极低行高、全屏层叠与摄影不是这次界面的验收条件；未为机械满足通用模板添加粒子或噪声遮罩。

## 后续顺序

先完成单平台具体动作的连接器与真实验证，再补持久化增量任务、消息事件、发送／发布幂等与结果核实。媒体资产与批量发布映射属于独立开发模块。随后再评估统一今天页、固定业务上下文栏和咨询三栏布局，保留旧能力与操作路径。

PRD 第 20–22 节已补入交互契约、逐项能力边界与 U01–U10 验收；第 18 节未覆盖目标继续保留。
