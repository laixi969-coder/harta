# 灵鹿增长 HARTA

销售每天用的获客工作台。

```bash
cd /Users/caiwenbin/Harta
node server.mjs
```

打开 http://127.0.0.1:5173/

建档时可以上传图片、PDF、Office 文档、文本和视频，也可以加入公开网页链接。系统会先归档原件、抽取正文、关键画面与视频语音，再形成资料总览、产品/人群/依据、风险和待补信息。

- 一次最多 20 个文件（单个 60MB、合计 120MB）和 20 条公开网页链接。多份长文、多页 PDF 和长视频会按资料均衡取样，不让前面的附件挤掉后面的证据。
- 读取完成后会在建档页展开资料总览、档案卖点、产品/人群/依据/风险/缺项和逐份资料摘要。点击“编辑梳理”可人工核对并保存；建档和后续重出使用保存版，原文件、抽取正文和语音转写保持只读以便回查。
- 主要粘贴框都有可见上限与计数：一句话卖点 300 字、销售补充 12,000 字、台账原话 4,000 字。超限时前后端都会明确拦截，不会静默截掉；销售补充会随客户保存并在重出时继续使用。
- 视频语音优先复用已配置的千问百炼渠道，自动调用 `qwen3-asr-flash`；没有千问渠道时使用本机 `whisper-cli`。可用 `HARTA_WHISPER_MODEL` 指定 Whisper 模型文件，也会自动查找 `data/models/ggml-{medium,small,base,tiny}.bin`。
- 视频处理需要 `ffmpeg`，旧版 Office、PPT 和表格转换需要 `libreoffice`。
- 管理员先在渠道内选择预选模型，再把一个配置完整的渠道设为当前。常规出档只用当前渠道；视觉分析先试当前渠道，再按卡片顺序尝试其他视觉模型。每次资料梳理会记录实际使用的渠道、模型和送入的画面数。
- 管理员可在每张渠道卡上标记所选模型的图片能力并执行“图片测试”。模型调用失败、返回非 JSON 或返回空梳理时会继续尝试下一个视觉模型；全部失败才降级到文字，并明确列出失败原因。
- 没有真正读取到的正文、画面或语音不会被当成诊断依据。
- 判断报告在「包裹」页可直接另存为 PDF 或 Word；有红线或硬限制时入口仍保留，并明确点名是哪几处。被卡住的报告可点「自动修复」：红线词、小红书标题超限、表单收医疗敏感信息都会送回模型改写留底（文案和外壳走改动记录，承接直接改字段），改不动的才留给销售手改。新生成的档在交付前同样自动过这一轮。
- 每批今日内容都进入「内容库」：可按关键词、状态、文案/平台外壳、方向和平台筛选，勾选后批量标为已选用、已发布或暂不用，并可安排发布日期。安排到今天的内容会回到首页「今日该发」；复制会自动标为已选用，记录回音或台账结果会自动标为已发布。
- 内容库支持把整批、已勾选内容或指定方向导出到本地。默认导出带批次说明的 Excel 工作簿，也可导出 Markdown；硬风险内容默认排除，用户可明确选择带风险导出。客户全部历史内容可另存为一份 Excel 备份。
- 出判断、出今日内容和补分镜都会显示真实生成阶段、进度与耗时：页顶任务中心跨页常驻，客户页里有进度面板。今日内容的进度按真实条数实报（已生成 34/50 条、外壳 40/80 条），面板还写明各步骤比例、上一批的真实耗时给出的预期。50 条文案拆三段并行出、四类平台外壳各一趟并行出；任何一段/一类失败只重修那一段，差数靠补段兜住，凑不满整批时只要够 40 条就交短批并把缺项记录在档——不会生成了一大部分又整批报错。任务在服务端跑，关掉页面回来进度还在。
