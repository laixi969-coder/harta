帮助用户在各个平台实现线索、获客、引流的工作台。产品目标与统计口径见 [GOAL.md](GOAL.md)。

当前主流程为：业务建档 → 需求与平台研究 → 一个主平台的 1–3 篇精选自然内容 → 用户按体验调整方向。支持 SearXNG 开源自建搜索、Brave Search 与可选的5118关键词数据。管理员在「设置 → 需求研究数据源」配置并测试连接；详细说明见 [研究接入文档](docs/RESEARCH.md)。

创作流程已升级为：提取可追溯的业务素材 → 提出 6–10 个简短创意 → 独立筛选 1–3 项 → 完整写作与事实核对。候选、入选和淘汰理由随批次保存，用户仍可一键生成；清单、编号和人称由内容用途决定，不再作为平台硬限制。

内容质量升级说明见 [从用户结果倒推的升级方案](docs/CONTENT-QUALITY-UPGRADE.md)。新版每篇内容附读者、问题、收益、依据与下一步，可在内容卡展开查看并随批次导出；研究和写作共享业务上下文，按最终编辑稿去重。交付前检查结构、质量，并另行对照原始资料核对经营承诺与行动一致性；有问题最多自动改写两次。模型辅助核对不等于独立事实认证。

- 平台内容现在可以整篇标记发布、记录有反馈 / 没反应，或直接点“记询价 / 成交”带入客户、平台与原内容。历史批次也可归因，同名客户按客户 ID 区分。
- 客户工作台新增“平台获客”：跨批次查看各平台的发布、反馈和跟进记录次数。数据由用户实际记录，不估算曝光量、去重线索人数或转化率。
- 到期未发布的内容持续留在首页，点“查看待发内容”直接进入对应批次。内容库可筛今天待发布、逾期未发布；没有结果时可清除筛选。
- 日常内容生成使用业务补充、已读取附件、需求研究与用户保存的方向。历史内容用于去重，逐篇反馈不作为生成前提。

首次部署：管理员尚未设密码时，需在启动服务的环境中设置 `HARTA_SETUP_PASSWORD`（12–128 字符的随机密码），再以管理员邮箱和该密码首次登录。没有配置时不会允许任意人抢先绑定。初始化成功后可移除该环境变量；不要把密码写进 Git 或日志。普通用户由管理员开通并私下领取 24 小时单次激活码，再在注册页填写邮箱、激活码和自设密码。密码重设也需要新的激活码。

公网域名部署必须设置 `HARTA_PUBLIC_ORIGIN=https://实际域名`，否则未知 Host 返回 421。仅当本机反向代理覆盖真实来源头时设置 `HARTA_TRUST_PROXY=loopback`；公网应通过 TLS 和边缘防护接入。限流、缓存、并发限制、反向代理配置及真实保护边界见 [服务保护与公网部署](deploy/native/SECURITY.md)。

建档时可以上传图片、PDF、Office 文档、文本和视频，也可以加入公开网页链接。系统会先归档原件、抽取正文、关键画面与视频语音，再形成资料总览、产品/人群/依据、风险和待补信息。

- 一次最多 20 个文件（单个 60MB、合计 120MB）和 20 条公开网页链接。多份长文、多页 PDF 和长视频会按资料均衡取样，不让前面的附件挤掉后面的证据。
- 读取完成后会在建档页展开资料总览、档案卖点、产品/人群/依据/风险/缺项和逐份资料摘要。点击“编辑梳理”可人工核对并保存；建档和后续重出使用保存版，原文件、抽取正文和语音转写保持只读以便回查。
- 主要粘贴框都有可见上限与计数：一句话卖点 300 字、销售补充 12,000 字、台账原话 4,000 字。超限时前后端都会明确拦截，不会静默截掉；销售补充会随客户保存并在重出时继续使用。
- 视频语音优先复用已配置的千问百炼渠道，自动调用 `qwen3-asr-flash`；没有千问渠道时使用本机 `whisper-cli`。可用 `HARTA_WHISPER_MODEL` 指定 Whisper 模型文件，也会自动查找 `data/models/ggml-{medium,small,base,tiny}.bin`。
- 视频处理需要 `ffmpeg`，旧版 Office、PPT 和表格转换需要 `libreoffice`。
- 管理员先在渠道内选择预选模型，再把一个配置完整的渠道设为当前。常规出档只用当前渠道；视觉分析先试当前渠道，再按卡片顺序尝试其他视觉模型。每次资料梳理会记录实际使用的渠道、模型和送入的画面数。
- 管理员可在每张渠道卡上标记所选模型的图片能力并执行“图片测试”。模型调用失败、返回非 JSON 或返回空梳理时会继续尝试下一个视觉模型；全部失败才降级到文字，并明确列出失败原因。
- 没有真正读取到的正文、画面或语音不会被当成诊断依据。
- 判断报告在「包裹」页可直接另存为 PDF 或 Word；有红线或硬限制时入口仍保留，并明确点名是哪几处。被卡住的报告可点「自动修复」：红线词、小红书标题超限、表单收医疗敏感信息都会送回模型改写留底（文案和外壳走改动记录，承接直接改字段），改不动的才留给销售手改。新生成的档在交付前同样自动过这一轮。
- 每批今日内容都进入「内容库」：可按关键词、状态、文案/平台外壳、方向和平台筛选，勾选后批量标为已选用、已发布或暂不用，并可安排发布日期。安排到今天的内容会回到首页「今日该发」；复制会自动标为已选用，记录回音或台账结果会自动标为已发布。
- 内容库支持把整批、已勾选内容或指定方向导出到本地。默认导出带批次说明的 Excel 工作簿，也可导出 Markdown；硬风险内容默认排除，用户可明确选择带风险导出。客户全部历史内容可另存为一份 Excel 备份。
- 出判断、出今日内容和补分镜都会显示真实任务阶段，任务在服务端运行。新主流程先研究、提取真实素材、独立比较候选，再生成精选内容和平台版本，通过既有质量与合规检查。
